# Disciplina 03 — Fundamentos de Front-End com React

Nesta disciplina são abordados os principais fundamentos do desenvolvimento front-end utilizando React, com foco na construção de interfaces, gerenciamento de estado e integração com APIs.

## Conteúdos da disciplina

- Introdução ao desenvolvimento front-end
- Componentes funcionais
- Props e eventos
- Estado de componentes
- Hooks
  - useState
  - useEffect
- Formulários e validação
- Consumo de APIs REST
- Axios e Fetch
- Context API
- Introdução ao Redux
- Organização de projetos React
- Vite
- ESLint e Prettier
- Boas práticas de desenvolvimento front-end
- Deploy de aplicações
