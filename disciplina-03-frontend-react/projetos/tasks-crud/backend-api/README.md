# Tasks CRUD — Backend API

API utilizada como back-end do projeto **Tasks CRUD** da disciplina **Fundamentos de Front-End com React**.

Este projeto fornece os endpoints utilizados pela aplicação front-end para gerenciamento de tarefas e autenticação de usuários.

## Objetivo

Disponibilizar uma API REST para integração com o projeto React desenvolvido durante a disciplina.

## Funcionalidades

- Criação de tarefas
- Listagem de tarefas
- Atualização de tarefas
- Exclusão de tarefas
- Autenticação de usuários
- Autorização utilizando JWT
- Integração com a aplicação front-end
