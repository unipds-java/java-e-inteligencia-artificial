# Disciplina 11 — Como Passar em Qualquer Entrevista de Emprego

Nesta disciplina são abordadas estratégias para preparação e desempenho em processos seletivos.

## Conteúdos da disciplina

- Entrevistas de RH
- Metodologia STAR
- Comunicação e alinhamento cultural
- Expectativas salariais
- Entrevistas técnicas
- Live coding
- Resolução de problemas
- Decisões arquiteturais
- Negociação salarial
- Técnicas de vendas e diferenciação profissional
