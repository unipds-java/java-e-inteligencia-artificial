# Disciplina 09 — Testes Automatizados e Qualidade de Código

Nesta disciplina são abordadas estratégias, ferramentas e boas práticas para construção de software confiável através de testes automatizados e análise de qualidade.

## Conteúdos da disciplina

- TDD
- JUnit Jupiter
- AssertJ
- Mockito
- SpotBugs
- PMD
- Testes de integração
- Testcontainers
- Métricas de qualidade
- Sonar
- Test Data Driven Approach
- ArchUnit
