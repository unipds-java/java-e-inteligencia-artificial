# Disciplina 09 — Testes Automatizados e Qualidade de Código

Nesta disciplina são abordadas estratégias, ferramentas e boas práticas para construção de software confiável e sustentável através de testes automatizados e análise de qualidade.

## Conteúdos da disciplina

- TDD — Test-Driven Development
- JUnit Jupiter
- AssertJ
- Mockito
- Análise estática com SpotBugs e PMD
- Testes de integração com Spring
- Testes de integração com Quarkus
- Testcontainers
- Métricas de qualidade
- Sonar
- Test Data Driven Approach
- ArchUnit
- Testes de performance
- Benchmarking

## Materiais práticos

Os exemplos e projetos utilizados ao longo da disciplina serão organizados neste diretório.
