# Disciplina 10 — Como Atrair as Melhores Vagas do Mercado

Nesta disciplina são abordadas estratégias para posicionamento profissional, fortalecimento de marca pessoal e construção de oportunidades no mercado de tecnologia.

## Conteúdos da disciplina

- Otimização do LinkedIn
- Social Selling Index (SSI)
- Networking estratégico
- SEO e palavras-chave
- Marca pessoal
- Portfólio técnico no GitHub
- Posicionamento por nível de carreira
