# Disciplina 05 — Software Design & System Design

Nesta disciplina são abordados conceitos fundamentais de design de software, Domain-Driven Design e projeto de sistemas escaláveis.

## Conteúdos da disciplina

### Software Design

- Design Patterns
  - Singleton
  - Factory
  - Strategy
  - Observer
  - Builder
  - Prototype
  - Adapter
  - Decorator
  - Proxy

- Domain-Driven Design (DDD)
  - DDD Estratégico
  - Bounded Context
  - Context Mapping
  - Linguagem Ubíqua
  - Patterns de integração
  - DDD Tático
  - Entity
  - Aggregate
  - Repository

### System Design

- Componentes de um sistema
- Front-end, back-end, bancos de dados e cache
- Escalabilidade vertical e horizontal
- CAP Theorem
- Latência e throughput
- SQL, NoSQL e NewSQL
- CAP / PACELC
- Sharding
- Load Balancers
- Redis e Memcached
- Replicação
- REST e gRPC
- Kafka e RabbitMQ
- Alta disponibilidade
- Circuit Breakers e Retries
- Failover
- Auto-healing

## Materiais práticos

Os exemplos, desafios e projetos referentes à disciplina serão organizados neste diretório.
