# Disciplina 06 — Concorrência e Multithreading

Nesta disciplina são abordados os principais conceitos de concorrência e processamento paralelo em Java.

## Conteúdos da disciplina

- Threads em Java
- Executors
- Fork/Join Framework
- CompletableFuture
- Programação reativa
- Locks
- Semáforos
- Synchronizers
- Concorrência e paralelismo
- Virtual Threads
