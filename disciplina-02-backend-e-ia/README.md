# Disciplina 02 — Desenvolvimento de Aplicações Back-End + IA

Nesta disciplina são abordados o desenvolvimento de aplicações back-end modernas com Java, Spring Boot, Quarkus e a integração de recursos de Inteligência Artificial.

## Conteúdos da disciplina

### Spring Framework e Spring Boot
- Configuração de projetos
- Desenvolvimento de APIs REST
- OAuth2 e JWT
- OpenAPI / Swagger
- Spring Data JPA
- Gerenciamento de transações
- WebFlux

### Quarkus
- Desenvolvimento de APIs REST
- Segurança e JWT
- Swagger / OpenAPI
- Panache
- GraalVM
- Microsserviços
- Kafka e mensageria
- Fault Tolerance
- Kubernetes Native
- Observabilidade

### IA Corporativa com Java
- LangChain4j
- IA preditiva e generativa
- RAG
- Embeddings
- Bancos vetoriais
- Agentes inteligentes
- Model Context Protocol (MCP)
- Segurança e governança
- Guardrails
- Cache e resiliência
- Observabilidade de aplicações com IA
