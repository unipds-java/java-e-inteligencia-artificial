# Enterprise AI com Java e LangChain4j

Conjunto de exemplos práticos da disciplina **Desenvolvimento de Aplicações Back-End + IA**, com foco na integração de aplicações Java com recursos de Inteligência Artificial utilizando **LangChain4j**.

## Objetivo

Demonstrar, de forma prática, como aplicações Java podem consumir, integrar e orquestrar recursos de IA generativa em cenários corporativos.

## Conteúdos trabalhados

- Integração de aplicações Java com modelos de IA
- LangChain4j
- Prompting e interação com LLMs
- Integração de contexto em aplicações
- RAG
- Embeddings
- Agentes e ferramentas
- Memória e gerenciamento de contexto
- Integrações com serviços externos
- Boas práticas para aplicações corporativas com IA
