# ☕ Java + Inteligência Artificial

Repositório oficial de materiais práticos, exemplos, desafios e projetos da **Pós-Graduação em Java + Inteligência Artificial da UNIPDS**.

Este repositório centraliza os conteúdos técnicos disponibilizados ao longo da formação, organizados de acordo com a sequência das disciplinas no AVA.

---

## 📚 Disciplinas

### 01 — Fundamentos do Java

Fundamentos da linguagem Java, orientação a objetos, estruturas de dados, APIs, Streams, NIO, tratamento de erros, concorrência, Maven e Gradle.

➡️ [Acessar Disciplina 01](./disciplina-01-fundamentos-java)

---

### 02 — Desenvolvimento de Aplicações Back-End + IA

Desenvolvimento back-end com **Spring Boot, Quarkus, APIs REST, segurança, Kafka, microsserviços e Inteligência Artificial com Java e LangChain4j**.

➡️ [Acessar Disciplina 02](./disciplina-02-backend-e-ia)

---

### 03 — Fundamentos de Front-End com React

Desenvolvimento front-end com **React**, componentes, hooks, formulários, gerenciamento de estado, consumo de APIs e integração com back-end.

➡️ [Acessar Disciplina 03](./disciplina-03-frontend-react)

---

### 04 — Arquitetura de Sistemas

Conceitos de arquitetura de software, **Clean Architecture, arquiteturas orientadas a eventos, Kafka, RabbitMQ, CQRS, Event Sourcing e desacoplamento**.

➡️ [Acessar Disciplina 04](./disciplina-04-arquitetura-de-sistemas)

---

### 05 — Software Design & System Design

Design Patterns, Domain-Driven Design, escalabilidade, disponibilidade, bancos distribuídos, comunicação entre serviços e projeto de sistemas.

➡️ [Acessar Disciplina 05](./disciplina-05-software-design-system-design)

---

### 06 — Concorrência e Multithreading

Threads, Executors, Fork/Join, CompletableFuture, locks, semáforos, synchronizers e Virtual Threads.

➡️ [Acessar Disciplina 06](./disciplina-06-concorrencia-multithreading)

---

### 07 — Infraestrutura e Cloud Computing

Docker, Podman, Kubernetes, AWS, CI/CD, Jenkins, GitHub Actions e infraestrutura para aplicações Java.

➡️ [Acessar Disciplina 07](./disciplina-07-infraestrutura-cloud)

---

### 08 — Bancos de Dados

Persistência de dados com **PostgreSQL, MongoDB, Redis, Cassandra e Neo4J**, além de JPA, Hibernate, Jakarta Data, Flyway e Liquibase.

➡️ [Acessar Disciplina 08](./disciplina-08-bancos-de-dados)

---

### 09 — Testes Automatizados e Qualidade de Código

TDD, JUnit, AssertJ, Mockito, SpotBugs, PMD, Testcontainers, Sonar, Test Data Driven Approach e ArchUnit.

➡️ [Acessar Disciplina 09](./disciplina-09-testes-qualidade)

---

### 10 — Como Atrair as Melhores Vagas do Mercado

LinkedIn, posicionamento profissional, networking, marca pessoal, portfólio técnico e estratégias para o mercado de tecnologia.

➡️ [Acessar Disciplina 10](./disciplina-10-carreira-e-mercado)

---

### 11 — Como Passar em Qualquer Entrevista de Emprego

Entrevistas de RH, metodologia STAR, entrevistas técnicas, live coding, negociação salarial e posicionamento profissional.

➡️ [Acessar Disciplina 11](./disciplina-11-entrevistas)
