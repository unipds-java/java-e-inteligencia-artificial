# Disciplina 08 — Bancos de Dados

Nesta disciplina são abordados conceitos de persistência, modelagem e integração com bancos de dados relacionais e NoSQL em aplicações Java.

## Conteúdos da disciplina

- Modelagem de bancos de dados relacionais
- JPA
- Jakarta Data
- Hibernate
- Consultas nativas
- JPQL
- Redis
- Cassandra
- MongoDB
- Neo4j
- Flyway
- Liquibase

## Projeto prático — Javify

Os conteúdos práticos da disciplina utilizam o projeto **Javify**, dividido em diferentes domínios de negócio.

Cada domínio possui implementações utilizando **Spring** e **Quarkus**, permitindo comparar diferentes abordagens para persistência e desenvolvimento de aplicações Java.

### Estrutura

- `administrativo/`
- `catalogo/`
- `historico-reproducao/`
- `recomendacoes/`

Dentro de cada domínio estão disponíveis as versões:

- `spring/`
- `quarkus/`
